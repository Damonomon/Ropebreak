# Hero video source

`www/media/backdrop-hero.mp4` is generated by `backdrop.py`: a 6-second seamless loop (30fps) of the Backdrop logo playing on the curved screen in `stage.jpg`.

What's in it:
- The logo matches the site header: "Backdr" + the orange drop + "p" in Bricolage Grotesque 800, with the peach → white → ice-blue fill and an orange/blue glow. The tagline sits underneath in spaced Karla capitals between two gold rules.
- The graphic is drawn flat, then mapped onto the screen's measured curve, with an LED pixel grid, the stage haze drifting over it, bloom and a faint reflection on the stage floor.
- Grime: dirt and streaks on the panel, faint module seams, scanlines and a rolling band, a muted grade, vignette, grain, dust and the odd scratch.
- Movement: a slow pulse, a shine across the logo and then the tagline, and a short glitch about two-thirds through. No strobes.

Owner decisions: muted orange and blue, a bright logo, no dead LED tiles, and the drop spaced tightly like the header logo.

## Re-render
Needs Python 3 with numpy and Pillow, and ffmpeg.
```
python3 tools/hero-video/backdrop.py /tmp/backdrop.mp4          # full-size master, ~10 min
python3 tools/hero-video/backdrop.py /tmp/frame 0,80            # or just check a few frames
ffmpeg -i /tmp/backdrop.mp4 -vf "scale=1280:720:flags=lanczos" -c:v libx264 -preset slow -tune grain -crf 27 \
  -pix_fmt yuv420p -profile:v high -level 4.0 -movflags +faststart -an www/media/backdrop-hero.mp4
ffmpeg -i www/media/backdrop-hero.mp4 -frames:v 1 -q:v 6 www/media/backdrop-hero-poster.jpg
```
If you replace the video, save it under a new file name and update `src`/`poster` in `www/index.html`: phones keep cached copies of a video URL, so an overwritten file can keep showing the old version.
`-tune grain` keeps the film grain; without it the encoder smears it into blotches.
